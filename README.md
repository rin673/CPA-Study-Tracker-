# 🎯 CPA Study Tracker (短答特化型 公認会計士学習管理アプリ)

公認会計士試験（短答式）の「講義消化」「3回転定着」「高速周回（忘却曲線・直前高速）」を完全自動化・可視化するための個人学習管理アプリケーション。

http://localhost:5173/

---

## 📱 主要機能 & 画面構成

### 1. 🧭 授業進行一覧 (ロードマップ)
- **ステージ切替**: 入門 / 基礎 / 応用 / 直前答練
- **進捗バー**: カリキュラム全体の進捗率 (%)
- **講義リスト**: 講義ごとの受講状態 (`未受講` / `受講済`) と 3回周回コンプリート状況 (`🟢🟢🟢`) の確認
- **詳細ダイアログ**: 講義カードタップでテキスト・ミニテスト・トレーニングの個別進捗（日付と評価）を表示

### 2. 🎓 講義消化 (3回定着) タブ
- **受講直後の初期復習（1〜3回目）**に特化したタスクリスト
- ワンタップ評価: `🔴 (要再講義)` / `🟡 (怪しい)` / `🟢 (完答)`
- タイマー機能（任意）

### 3. 🔄 高速回転 (忘却曲線 / 直前周回) タブ
- **3回完了論点の周回モード**
- 絞り込みフィルター: `講義別` / `テキスト(論点)別` / `トレーニング別` / `答練・過去問`
- 直前高速周回モード: 設定した周回ペース（例: 2週間で1周）から日割りノルマを自動計算

### 4. 📅 カレンダー & 動的スケジュール調整
- 日付別の予定タスク一覧
- **タスク移動ダイアログ**:
  - `単発移動`: 選択したタスクのみを指定日へ移動
  - `連動スライド`: 復習間隔（忘却曲線）を維持したまま、以降の復習予定も自動で未来へ追従スライド

### 5. 📊 成績 & 📚 本棚管理
- **答練成績管理**: 得点と平均点の差分から自動カラー判定 (`🟦 平均+10以上` / `🟨 標準` / `🟥 平均以下`)
- 平均以下の範囲をワンタップで「要復習タスク」へ再投入
- **本棚UI**: 教材ごとの周回率可視化 & 復習間隔（スパルタ/標準/ゆったり）の設定
